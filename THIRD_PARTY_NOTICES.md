# Third-Party Notices

Midnight Faucet API uses third-party software distributed under open-source licenses. The authoritative dependency versions are recorded in `yarn.lock`, Nix lock files, and container manifests.

Each dependency's copyright and license terms remain the property of its respective authors. Source packages and their license texts are available through the registries and source repositories identified by the lock files.

Before publishing a binary, container image, or npm package, release owners must generate and review the distribution's software bill of materials and include any attribution or license text required by the dependencies actually bundled in that artifact.

No third-party source is intentionally modified or vendored in this repository unless the relevant path states otherwise.
