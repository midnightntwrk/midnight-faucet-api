# Getting Support

Choose the channel that matches your request.

## Questions and usage help

Open a thread in [GitHub Discussions](https://github.com/midnightntwrk/midnight-faucet-api/discussions) for general usage questions.

## Bugs

Open an issue using the **Bug report** form. Include the version, environment, expected behavior, actual behavior, and minimal reproduction steps.

## Feature requests

Open an issue using the **Feature request** form. Describe the use case and problem before the proposed solution.

## Security vulnerabilities

Do not open a public issue. Follow [SECURITY.md](./SECURITY.md) and use GitHub private vulnerability reporting.

## Code contributions

Read [CONTRIBUTING.md](./CONTRIBUTING.md) for setup, testing, commit, and pull-request requirements.

## Code of conduct concerns

Email [legal@midnight.foundation](mailto:legal@midnight.foundation) and see [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md).
